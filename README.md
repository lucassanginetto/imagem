# imagem

imagem is a keyboard centric image viewer written using PyQt5.

Heavily inspired by zathura, the document viewer.

## Dependencies

- Python
- PyQt5

## Installation

```sh
# Clone the repo
git clone https://github.com/lucassanginetto/imagem.git

# Make sure you're inside the imagem directory
cd imagem

# Make sure the installation script is executable
chmod +x install.sh

# Install
sudo ./install.sh
```

## Usage

```sh
# Launch an empty imagem instance
imagem

# Open a folder containing images
imagem ~/Images

# Open a specific image file
imagem ~/Downloads/wallpaper.png

# For the list of available keybindings, read the manpage.
man imagem
```

## Uninstallation

```sh
# Make sure you're inside the imagem directory
cd imagem

# Uninstall
sudo ./install.sh uninstall
```
